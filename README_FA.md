## 📖 درباره پروژه

این پروژه نسخه کاملاً بومی‌سازی‌شده، فارسی و آفلاین شبیه‌ساز زندگی **«یک در هشت میلیارد» (1 in 8 Billion)** است.

این شبیه‌ساز بر اساس آمار واقعی و معتبر ۱۷۲ کشور و منطقه جهان (برگرفته از سازمان ملل، بانک جهانی، سازمان بهداشت جهانی و یونیسف) زندگی یک انسان تصادفی از زمان تولد تا پایان عمر را با رویدادها، انتخاب‌ها، بحران‌ها و دستاوردهای واقعی بازسازی می‌کند.

---

## 🌟 قابلیت‌های نسخه فارسی

- **ترجمه کامل و روان**: بیش از ۱۷,۰۰۰ رویداد، سناریو، تصمیم، بیماری، کاراکتر و پیام به فارسی سلیس ترجمه شده‌اند.
- **تایپوگرافی زیبا با فونت وزیرمتن**: تمامی متون، دکمه‌ها و پنجره‌ها با فونت استاندارد Vazirmatn و جهت راست‌چین (RTL) نمایش داده می‌شوند.
- **رایگان‌سازی همه امکانات**: تمام قابلیت‌هایی که نیازمند پرداخت دلاری بودند (مثل ساخت یادبودها، تزئینات دهکده و بسته‌ها) کاملاً رایگان و باز شده‌اند.
- **اجرای آفلاین و مستقل**: هیچ وابستگی به سرویس‌های تحریم‌شده یا اسکریپت‌های سنگین آنلاین ندارد و به صورت محلی با بالاترین سرعت اجرا می‌شود.
- **پشتیبانی کامل از صفحات جانبی**: شامل ۱۷۲ صفحه تفصیلی کشورها، کتاب‌های داستان بازی، و راهنمای آموزشی برای معلمان و کلاس‌های درس.

## 💻 راهنمای اجرای لوکال (روی کامپیوتر شما)

می‌توانید کل پروژه را به سادگی به صورت آفلاین اجرا کنید:

### روش ۱: با پایتون (ساده‌ترین روش)
ترمینال یا CMD را در پوشه پروژه باز کنید و دستور زیر را بنویسید:
```bash
python -m http.server 8080
```
سپس آدرس زیر را در مرورگر باز کنید:
[http://localhost:8080](http://localhost:8080)

### روش ۲: با افزونه Live Server در VS Code
روی فایل `index.html` کلیک راست کرده و گزینه **Open with Live Server** را بزنید.

### روش ۳: با Node.js
```bash
npx serve .
```
